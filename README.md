# Подбор новостроек · Часть 2, трек А

Подборщик на Python использует 15 проектов из исправленной таблицы Части 1. В `projects.csv` перенесены названия, города, районы, классы и стартовые цены за квадратный метр, включая 421 000 ₽/м² для ЖК «Веер» и 275 472 ₽/м² для ЖК «Покровский парк».

## Запуск

Распакуйте архив. В папке с `podbor.py` и `projects.csv` выполните команду:

```sh
python3 podbor.py
```

Нужен Python 3.8 или новее. На Windows можно использовать `py podbor.py`. Дополнительные пакеты не нужны.

Выберите город, введите бюджет в рублях и площадь в м². Например, для Москвы, 30 000 000 ₽ и 60 м² программа покажет три проекта от 17 880 000 до 25 260 000 ₽.

## Как считается подбор

Для каждого ЖК выбранного города программа умножает стартовую цену за м² из таблицы на желаемую площадь, округляет результат до рубля и сравнивает с бюджетом. Она показывает до трёх самых доступных вариантов. При меньшем количестве совпадений программа выводит все подходящие ЖК.

Результат — приблизительная оценка по данным Части 1. Площадь, наличие лота и его фактическую стоимость нужно уточнить у продавца.
